# Deliverables

Tato složka obsahuje zmrazené, reprodukovatelné výstupy jednotlivých verzí experimentu.

Aktuální verze je v [`2026-09-01/`](2026-09-01/). Její podadresáře oddělují:

1. materiály k prvnímu rozeslání hodnotitelům;
2. odtajňovací a auditní balíček předávaný až po uzavření posudku;
3. úplný soukromý archiv sestavení a procesu.

Obsah datované složky generuje a kontroluje `.github/workflows/build-review-package.yml`. Ruční změny v generovaných binárních souborech se nemají provádět; správný postup je upravit zdrojové soubory a znovu spustit build.
